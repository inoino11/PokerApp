# 仕様書（初版）

テキサスホールデムのチップのやり取りを、1 台の端末だけでデジタル化する。
仲間内でチップを使わずにポーカーを楽しむためのツールで、実際のルールに厳密には合わせない。

- クラウドなどの外部サービスは使わない。データはすべて端末の中に保存する。
- 操作はディーラー役の 1 人が行う。主にスマホを縦にして使う想定。
- 操作は、なるべく 1 ページの中で完結させる。設定はボトムシートかダイアログで開く。
- トーナメントかリングゲームかは選ばせない。ブラインドが時間で上がるかどうかだけで決まる。

---

## 1. プレイヤー

### 1-1. 席
- 席は最大 10。追加した人は一覧の最後に座る。
- 「追加」「席替え」のボタンは一覧の上に置く。人数が増えても位置が変わらず、続けて押せるようにするため。「席替え」は 2 人そろうまで押せない形で出しておく（あとから出すと「追加」の幅が変わるため）。
- 並び順は「席替え」モードで直す。行の右端のつまみ（≡）をドラッグして、離れた席へも 1 回で動かせる。席替え中はポットと操作パネルを隠し、行をタップしてもメニューは開かない。1 回のドラッグが UNDO の 1 手になる。
- 席替えはハンドの合間（ハンドが始まっていないとき）だけできる。ハンドの途中に並びを変えると、一覧の並びと手番の順がずれて見えるため。
  - ハンドの途中に「席替え」を押したら、理由を知らせて席替えモードには入らない。
  - 席替え中に UNDO などでハンドの途中に戻ったら、席替えモードを抜ける。
- ハンドの合間は、次のハンドでボタンになる人に「次D」を表示する。次のボタンは前のボタンの人の次の席なので、前のボタンの人を席替えで動かすと、ボタンもその人について動く。
- 次のハンドのボタン（D）は手で選べる。ハンドの合間にプレイヤーの画面を開き、「次のハンドの D にする」を押す（UNDO の 1 手）。
  - 選べるのはハンドの合間だけで、次のハンドに参加できる人（着席中でチップがある人）だけ。すでに「次D」の人の画面にはボタンを出さない。ハンドの途中で違うと気づいたら、UNDO でハンドの前に戻してから選ぶ。
  - 選んだ人がボタンになり、SB・BB はその左から決まる。その次のハンドからは、選んだ人を起点に自動で回る。
  - ハンドを始める前に、選んだ人を席替えで動かしたら、ボタンもその人について動く。一時離席・退席・チップ 0 になったら、選んだことは取り消して自動の規則に戻す（戻ってきても、選び直すまでは自動のまま）。
- 名前は追加した順に `P1`, `P2`, … と自動で付ける。あとから変えられる（変えるときだけキーボードを出す）。
- 見分けやすいように、プレイヤーごとに色を付ける。
- D・SB・BB・3rd・次D の札は、名前の下の行の左端に出す（名前の後ろに付けると、名前の長さで位置がずれるため）。
- オールインした人には、同じ行に赤い縁と黒い地の三角の札を出す（卓でオールインした人の前に立てる札に見立てる）。札は小さく文字が読めないので、中にはアイコンのどんぐりを描く。
- 行をタップすると、そのプレイヤーの画面を開く。名前と手元のチップは入力欄で直し、「確定」でまとめて変える（UNDO の 1 手）。「キャンセル」なら何も変えない。一時離席・着席・退席は、ボタンを押したときにすぐ変える。

### 1-2. 状態
| 状態 | 意味 | 席 | ハンドに参加 | ブラインド |
|---|---|---|---|---|
| 着席 | ふつうに参加している | ある | する | 払う |
| 一時離席 | 席とスタックはそのままで、少し抜けている | ある | しない | 払わない |
| 退席 | スタックを持って帰った | ない | しない | 払わない |

- スタックが 0 になったら、自動で一時離席にする。チップを足せば着席に戻せる。
- 一時離席から着席に戻った人は、次のハンドから参加する。

### 1-3. 追加・退席・離席
- **追加**はいつでもできる。ハンドの途中で追加した人は、次のハンドから参加する。ブラインドの位置に座れば、そのブラインドを払う。
- **退席**と**一時離席**は、今のハンドのポットに参加していなければ（チップを出していないか、すでに降りていれば）、いつでもできる。まだチップを出していない参加者が抜けたときは、降りたことにする。

### 1-4. スタックの変更
- ハンドに参加していない人のスタックは、いつでも変えられる。
- 参加中の人は、手元に残っている分（ポットに出していない分）だけ変えられる。ポットに出した額は変えられない。
- 追加したときの額をバイインとして、あとで増やした分をリバイとして記録しておく（今は画面に出さない。精算表を作るときに使う）。
- 額は、名前と同じ入力欄で入れる（端末のキーボードを出してよい。数字用のキーボードを出す）。全角の数字・カンマ入りも読む。数値として読めない内容で欄を離れたら、直前に読めた値へ戻す。「+最初のスタックの半分」「+最初のスタック」のボタンでも足せる。

## 2. ブラインド

### 2-1. ブラインドテーブル
- 各レベルに、SB・BB・3 番目のブラインドの額を、ユーザーが自由に決める。
- トリプルブラインドは、使う／使わないを切り替えられる。使うときは、BB の次の席の人が 3 番目のブラインドを払う。
  - 参加者が 3 人以下のときは、トリプルブラインドを使わない（SB と BB だけにする）。
  - プリフロップでは、3 番目のブラインドの次の人から行動を始め、3 番目のブラインドの人が最後に行動する。
- アンティは初版では扱わない。

### 2-2. ブラインドアップ
- レベルの時間は、全レベル共通で 1 つの値（分）にする。0 にすると、ブラインドは上がらない（固定）。
- 時間が来たら、**次のハンドから**新しいレベルを使う。ハンドの途中では変えない。
- 最後のレベルまで来たら、そのレベルのまま続ける（頭打ち）。
- 休憩は、一時停止ボタンで時計を止めて取ってもらう。休憩用の行はテーブルに入れない。
- レベルは手動で上げ下げでき、残り時間も調整できる。固定（0 分）のときも、レベルを手動で変えてレートを変えられる。
  - ブラインドの帯で、レベルの表示の左右にある矢印（‹ ›）で 1 つずつ上げ下げする。最初のレベルでは ‹、最終レベルでは › を押せない。
  - 残り時間は、時刻をタップして開くメニューで ±1 分する。
  - 最終レベルでは、時刻と再生・一時停止のボタンを出さず、「最終レベル」とだけ出す（時計を進める意味がないため）。
- 一時停止ボタンと時計は、固定（0 分）のときは表示しない。
- ブラインドの帯の額の下に、次のレベルの額を「Next 200 / 400」と小さく出す。上がる前に心づもりができるようにするため。固定（0 分）と最終レベルでは出さない。「次のハンドから」を出している間は、同じ場所なので出さない。
- レベルが上がったら、音とバイブと画面の点滅で知らせる。
  - 残り 1 分を切ったら、短い音 1 回とバイブで知らせ、時刻を警告色にする（通知は出さない）。開き直した直後や、ラウンドが 1 分以下のときは鳴らさない。最終レベルでは知らせない。
  - 音は、アプリを開いてから画面のどこかを一度タップすると鳴るようになる（iPhone はタップの中でないと音を使わせないため）。他のアプリで流している音楽は止めずに重ねて鳴らす。音楽を聴く音量でも聞こえるよう、音は大きめ・長め（0.4 秒）にし、スマホのスピーカーで聞き取りやすい音色（三角波）にする。消音モード・画面ロック中・アプリが裏にある間は鳴らない。iPhone ではバイブしない。
  - 通知は「ブラインドアップ」と、改行して「Lv2（100 / 200）」のように出す。ハンドの途中なら、ブラインドの帯の額の下に「次のハンドから」と出る。
- 残り時間は「開始した時刻＋止めていた時間の合計」から毎回計算する。ページを開き直しても、アプリが裏に回っても、時計がずれないようにするため。

### 2-3. プリセット
- ブラインドテーブル・レベルの時間・トリプルブラインドを使うか・最初のスタックを、まとめて 1 つのプリセットとして保存する。最小チップの設定はプリセットに入らない。
- 設定画面では、プリセットに入る設定を 1 つの枠で囲む。枠の上で読み込み、枠の下で名前を付けて保存する。最小チップの設定は枠の外に置く。
- レベルの時間の欄は「ラウンド（分）」と書き、「0 ならブラインド固定」と添える。
- 組み込みのプリセットを数個用意する（短いトーナメント、標準のトーナメント、ブラインド固定のキャッシュゲームなど）。ユーザーも自分のプリセットを保存・削除できる（削除するときは確認する）。
- プリセットは一覧から選んだ時点で設定の欄に読み込む（ゲームに使うのは設定の「確定」を押したとき）。

## 3. ハンドの進行とアクション

### 3-1. 自動で進めること
- ディーラーボタンと、SB・BB（と 3 番目のブラインド）を自動で回す。
  - 2 人のときは、ボタンの人が SB を払う。
  - ブラインドの位置の人が抜けても、厳密なデッドボタンにはしない。単純に次の参加者へ回す。
- 次に行動する人を、行の枠の色で強調する（「手番」の文字は出さない）。
- ベットがそろったら、次のストリート（フロップ・ターン・リバー）へ自動で進む。カードは入力しない。ストリートは表示の区切りにだけ使う。
- 1 人を残して全員がフォールドしたら、勝敗の入力をとばして、その人にポットを渡す。
- 行動できる人が 1 人以下になったら（ほかの全員がオールイン）、残りのストリートをとばして勝敗の入力へ進む。
- 誰もコールしなかったベットの超過分は、出した人に返す。

### 3-2. アクション
- 前に出ている額が 0 のとき：**Fold** / **Check** / **Bet…** / **All-in**
  - ただでチェックできる場面で降りるのはほぼ押し間違いなので、Fold は左端に小さく目立たない形で出す。
- 前に出ている額があるとき：**Fold** / **Call** / **Raise…** / **All-in**
- Bet… / Raise… を押すと、額を選ぶ画面（3-3）に切り替わる。額を選ぶ画面では Fold・Call・All-in を出さず、「戻る」と「Raise to ○○ で確定」だけを出す。% ボタンの押し損ねでアクションしてしまわないようにするため。
- 操作パネルの中身が切り替わった直後（アクション・勝者の確定・ハンドの開始・額を選ぶ画面の開閉のあと）は、0.175 秒だけ入力を受け付けない。二度押ししたとき、同じ位置に出た次の人のボタンを押さないようにするため。
- スタックがコールする額に足りないときは、Call を「Call (All-in)」と表示する。
- 最小レイズに足りない額でも打てる。そのときは額の色を変えて注意を出すだけにする。
- 額は「Raise to（このストリートで出す合計の額）」で表示する。

### 3-3. ベット額の入力（キーボードは出さない）
額を選ぶ画面に、次の 3 つを並べる（上から % ボタン、± と額、確定ボタンの順。% ボタンを確定ボタンから離す）。
1. **ポットの % ボタン**（33% / 50% / 75% / 100% / 150%）
   - **今、場に出ているチップの合計**（前のストリートまでのポットと、このストリートで出された分すべて）を基準にする。
   - **このアクションで新しく出す額 ＝ 今のポット × %**。つまり 100% を打つと、ポットはちょうど 2 倍になる。
   - 新しく出す額がコールする額より少ないボタンは、押せなくする。
   - ボタンの中に、押したときの額（Raise to）を小さく薄く添える。Max にはスタック全部の額を添える。
2. **± ボタン**：最小チップ単位（初期値は今のレベルの SB）ずつ増減する。長押しすると速く変わる。下限は「コールする額＋最小チップ単位 1 つ分」、上限はスタック全部。
3. **テンキー**：画面の中に描くボタン（0–9 / 00 / 000 / ←）。ちょうどの額を打ちたいときに、タップして開く。

### 3-4. 最小チップ単位（丸め）
- 最小チップ単位（例: 25, 100）を決め、% で出した額をその単位に丸める（いちばん近い値にし、スタックを超えたらスタック全部にする）。
- 初期値は今のレベルの SB にする。設定で値を変えられ、丸めそのものもすぐ切り替えられる（オン／オフ）。
- 設定画面の見出しは「最小チップ」。スイッチは「端数を丸める」（下に「% ボタンの額とチョップの分け方」と添える）と「今の SB に合わせる」で、後者をオフにすると「最小チップ」の欄が出る。
- チョップの端数も同じ単位で分け、余りはボタンの左から数えて最初の勝者に渡す。

## 4. 勝敗の入力

ポットごとに勝者を選ぶ。
1. ポットとサイドポットは、各プレイヤーが出した額から自動で計算する。フォールドした人のチップもポットに入るが、その人に受け取る権利はない。
2. まず、メインポット（参加者全員に権利がある）の勝者をタップする。1 人なら Win、複数ならその人たちで Chop。残りの人は自動で Lose。
3. 勝者がすべてのサイドポットにも権利を持っていれば、そこで決まる。
4. 勝者に権利がないサイドポットが残っていれば、その権利を持つ人だけを表示して、次の勝者を選ぶ。これをすべてのポットが決まるまで繰り返す。
- パネルの見出しは「Main pot 1,600 の勝者」「Side pot 1,700 の勝者」のように出す。サイドポットが複数あっても番号は付けず、額で見分ける。
- 見出しの下に、このあと決めるポットを「このあと: Side pot 1,700 / Side pot 900」のように小さく出す。最後のポットでは出さない。
- 勝者を選んでいる間は、上のポットの帯（ストリートと Pot の合計）を隠す。パネルの見出しと重なるため。
- 決めるボタンは、誰も選んでいなければ「勝者未選択」（押せない）、1 人でも選べば「確定」。チョップ（複数選んだとき）でも同じ「確定」。
5. 確定したら、チップを配って次のハンドへ進む。

## 5. UNDO / REDO

- 次の操作を、それぞれ 1 手として戻せる：アクション、勝敗の確定、ハンドの開始、プレイヤーの追加・退席・離席・席の移動、名前の変更、スタックの変更、D の選択、設定の変更、始め直し。
- ハンドをまたいでも戻せる。
- 時計（経過時間・一時停止・レベルの手動変更）は UNDO の対象外。手動で変えたレベルは、ブラインドの帯の矢印で戻す。
- 新しい操作をしたら、REDO の履歴は消える。
- 履歴も端末に保存し、ページを開き直したあとも戻せるようにする。上限は 100 手で、古いものから消す（それより前まで戻すことはまずないため）。
- 実装では、ゲームの状態をまるごと変えられないオブジェクトにし、操作のたびに新しい状態を作って履歴に積む。
- 確認ダイアログは原則出さない（UNDO で戻せるため）。ただし「プリセットの削除」だけは確認する。始め直しは、ダイアログで種類を選ぶことが確認を兼ねる。

## 7. 画面（1 ページ）

```
┌──────────────────────────────┐
│ Lv3  200 / 400 / 800   12:34 ⏸ │ ← 固定（0 分）なら時計と ⏸ を出さない
│ ↶ ↷                          ⚙ │ ← UNDO/REDO・設定
├──────────────────────────────┤
│  席の一覧（縦のリスト）              │
│  名前 / スタック / このストリートの額    │
│  D・SB・BB と状態（名前の下の行）       │
│  次に行動する人を強調。タップでメニュー   │
│  （名前・スタックの変更、離席、退席）     │
├──────────────────────────────┤
│ Flop  Pot 3,200（Side 1,000）     │
├──────────────────────────────┤
│ [Fold] [Call] [Raise] [All-in]   │
│ 33% 50% 75% 100% 150%  − 1,200 ＋ │ ← テンキーはタップで開く
└──────────────────────────────┘
```
- 勝敗を入力するときは、下の部分が「勝者を選ぶパネル」に切り替わる。
- 設定（ブラインドテーブル、プリセット、最小チップ単位、丸めのオン／オフ）は、ボトムシートで開く。
- 遊んでいる最中の画面に出すポーカー用語は英語で書く（Preflop / Flop / Turn / River / Showdown、Main pot / Side pot、Chop、Fold など）。卓で口にする言葉は英語、アプリの操作（追加・確定・一時離席など）は日本語にし、1 つのボタンの中で英語と日本語を混ぜない。設定画面の説明文などは日本語でよい。
- ダイアログを何もせず閉じるボタンは「キャンセル」、入力を反映して閉じるボタンは「確定」にそろえる。席替えの「完了」（並べ替えは離すたびに反映済みで、モードを抜けるだけ）、額を選ぶ画面の「戻る」、プリセットの「保存」「削除」は意味が違うので別の言葉にする。
- 画面の文は体言止めに寄せる（「〜不可」「〜可能」「〜完了」「〜済み」）。体言止めにしにくいときだけ常体にする。確認の問いかけ（「〜を削除しますか？」）と、ページ全体に出るエラー（「ページが見つかりません」「起動に失敗しました」）は、ですます調にする。
- 句点「。」は、2 文以上続く説明文だけに付ける。1 文で終わる短い表示（ボタン・見出し・欄の説明・通知・エラー）には付けない。
- ブラインドの額は「50 / 100」のように、/ の前後に半角スペースを入れる。額の途中では折り返さない（改行しない空白を使う）。
- ポットの帯のストリート名は、ストリートごとに色を分ける（Preflop 灰青・Flop 緑・Turn 橙・River 青）。
  - ストリート名の左に、場に開いたカードの枚数（Preflop 0・Flop 3・Turn 4・River 5 枚）をカードの形で並べる。卓と同じく 3 枚と 1 枚・1 枚の間をあけ、開いたカードには、ストリートの色でどんぐりを描く（アイコンのトランプと同じ形）。
- 各行のスタックの下に、BB の何倍かを「32 BB」のように小さく出す。ハンドの途中はそのハンドの BB、合間は次のハンドの BB で割る。10 BB 未満は小数 1 桁（4.5 BB）にし、どちらも切り捨てる。スタックが 0 なら出さない。
- 降りた人・一時離席の人・次のハンドから参加する人の行は、薄く表示する。
- ハンドの合間の下のボタンは、最初は「ディール開始（50 / 100）」、2 回目からは「次のハンドへ（…）」。参加できる人（着席中でチップがある人）が 2 人に満たないときは押せず、「参加者待ち（あと N 人）」と出す。説明文は出さない。
- シマリスの絵は、誰もいない卓（プレイヤーが 0 人のとき）に薄く置き、エラーの画面（ページが見つかりません・問題が発生）の見出しの上にも置く。ゲームの進行中には出さない。
- 画面上部の通知は、タップ（✖ に限らずどこでも）か、どの向きへのスワイプでも消せる。少し（50px 未満）動かしただけなら元の位置に戻る。消えるときの薄くなる時間は 0.2 秒にする（長いと、押しても消えないように見え、見えない通知が上の帯のボタンをふさぐため）。
- ボタンを続けて押しても、ダブルタップで画面を拡大しない。2 本指で広げる拡大はできる。
- 上の帯の UNDO / REDO は、矢印の下に「戻す」「やり直す」と書く。隣の「始め直す」と矢印の形が似ているため。
- 時計を止めている間は、残り時間をグレーにしてゆっくり明滅させる。再生・一時停止のボタンは、切り替えても大きさと位置を変えない。

## 8. その他
- ゲーム中は、画面が消えないようにする（Wake Lock API）。
- 状態は操作のたびに端末に保存する。タブを閉じても、そのまま再開できる。
- 上の帯の「始め直す」（↻）から、ゲームを始め直す。押すとダイアログで次のどちらかを選ぶ（「キャンセル」で何もしない）。
  - **同じメンバーで始める**: 退席した人を除く全員を、名前・色・席順のまま初期スタックに戻す（チップ 0 や一時離席の人も着席に戻す）。「誰かのチップがなくなったから仕切り直す」ときに使う。
  - **全部消して始める**: プレイヤーも消す。
  - どちらも、途中のハンドと前のハンドの結果を消し、次の D は先頭の人にし、時計は Lv1 に戻して止める。設定とプリセットは残す。ハンドの途中でも使える。
  - どちらも UNDO の 1 手として戻せる（履歴は消さない）。ただし時計は UNDO の対象外なので、Lv1 に戻ったままになる。
- バックアップ（ファイルへの書き出し・読み込み）は持たない。ゲームはその場の一戦のためのもので、終わったら消えてよい。
  - 端末への自動保存は、一戦の途中のリロードやタブの破棄から守るためだけに使う。一戦が終わったら「始め直す」で次のゲームにする。
  - プリセットは設定なので、端末に残し続ける。

## 9. 初版では扱わないもの
- アンティ、ストラドル（ストラドルが必要なら、トリプルブラインドで代わりにする）
- 精算表（バイイン・リバイの記録だけはしておく）
- ハンドの履歴、勝ち数などの統計（あとで足せる設計にはしておく）
- 最小レイズに足りないオールインのあとで、レイズできるかどうかの厳密な判定
