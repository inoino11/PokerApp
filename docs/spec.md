# 仕様書（初版）

テキサスホールデムのチップのやり取りを、1 台の端末だけでデジタル化する。
仲間内でチップを使わずにポーカーを楽しむためのツールで、実際のルールに厳密には合わせない。

- クラウドなどの外部サービスは使わない。データはすべて端末の中に保存する。
- 操作はディーラー役の 1 人が行う。主にスマホを縦にして使う想定。
- 操作は、なるべく 1 ページの中で完結させる。設定はボトムシートかダイアログで開く。
- トーナメントかリングゲームかは選ばせない。ブラインドが時間で上がるかどうかだけで決まる。

---

## 1. プレイヤー

### 1-1. 席
- 席は最大 10。並び順は追加するときに指定でき、あとからドラッグで入れ替えられる。
- 名前は追加した順に `P1`, `P2`, … と自動で付ける。あとから変えられる（変えるときだけキーボードを出す）。
- 見分けやすいように、プレイヤーごとに色を付ける。

### 1-2. 状態
| 状態 | 意味 | 席 | ハンドに参加 | ブラインド |
|---|---|---|---|---|
| 着席 | ふつうに参加している | ある | する | 払う |
| 一時離席 | 席とスタックはそのままで、少し抜けている | ある | しない | 払わない |
| 退席 | スタックを持って帰った | ない | しない | 払わない |

- スタックが 0 になったら、自動で一時離席にする。チップを足せば着席に戻せる。
- 一時離席から着席に戻った人は、次のハンドから参加する。

### 1-3. 追加・退席・離席
- **追加**はいつでもできる。ハンドの途中で追加した人は、次のハンドから参加する。ブラインドの位置に座れば、そのブラインドを払う。
- **退席**と**一時離席**は、今のハンドのポットに参加していなければ（チップを出していないか、すでに降りていれば）、いつでもできる。まだチップを出していない参加者が抜けたときは、降りたことにする。

### 1-4. スタックの変更
- ハンドに参加していない人のスタックは、いつでも変えられる。
- 参加中の人は、手元に残っている分（ポットに出していない分）だけ変えられる。ポットに出した額は変えられない。
- 追加したときの額をバイインとして記録する。額を増やすときは「リバイとして精算に計上する」かどうかを選べる（計上しなければ手修正の扱い）。
- 額の入力には、ベット額と同じテンキーを使う（3-3）。

---

## 2. ブラインド

### 2-1. ブラインドテーブル
- 各レベルに、SB・BB・3 番目のブラインドの額を、ユーザーが自由に決める。
- トリプルブラインドは、使う／使わないを切り替えられる。使うときは、BB の次の席の人が 3 番目のブラインドを払う。
  - 参加者が 3 人以下のときは、トリプルブラインドを使わない（SB と BB だけにする）。
  - プリフロップでは、3 番目のブラインドの次の人から行動を始め、3 番目のブラインドの人が最後に行動する。
- アンティは初版では扱わない。

### 2-2. ブラインドアップ
- レベルの時間は、全レベル共通で 1 つの値（分）にする。0 にすると、ブラインドは上がらない（固定）。
- 時間が来たら、**次のハンドから**新しいレベルを使う。ハンドの途中では変えない。
- 最後のレベルまで来たら、そのレベルのまま続ける（頭打ち）。
- 休憩は、一時停止ボタンで時計を止めて取ってもらう。休憩用の行はテーブルに入れない。
- レベルは手動で上げ下げでき、残り時間も調整できる。固定（0 分）のときも、レベルを手動で変えてレートを変えられる。
- 一時停止ボタンと時計は、固定（0 分）のときは表示しない。
- レベルが上がったら、音とバイブと画面の点滅で知らせる。
- 残り時間は「開始した時刻＋止めていた時間の合計」から毎回計算する。ページを開き直しても、アプリが裏に回っても、時計がずれないようにするため。

### 2-3. プリセット
- ブラインドテーブル・レベルの時間・トリプルブラインドを使うか・最初のスタックを、まとめて 1 つのプリセットとして保存する。
- 組み込みのプリセットを数個用意する（短いトーナメント、標準のトーナメント、ブラインド固定のキャッシュゲームなど）。ユーザーも自分のプリセットを保存・削除できる（削除するときは確認する）。

---

## 3. ハンドの進行とアクション

### 3-1. 自動で進めること
- ディーラーボタンと、SB・BB（と 3 番目のブラインド）を自動で回す。
  - 2 人のときは、ボタンの人が SB を払う。
  - ブラインドの位置の人が抜けても、厳密なデッドボタンにはしない。単純に次の参加者へ回す。
- 次に行動する人を強調表示する。
- ベットがそろったら、次のストリート（フロップ・ターン・リバー）へ自動で進む。カードは入力しない。ストリートは表示の区切りにだけ使う。
- 1 人を残して全員がフォールドしたら、勝敗の入力をとばして、その人にポットを渡す。
- 行動できる人が 1 人以下になったら（ほかの全員がオールイン）、残りのストリートをとばして勝敗の入力へ進む。
- 誰もコールしなかったベットの超過分は、出した人に返す。

### 3-2. アクション
- 前に出ている額が 0 のとき：**Fold** / **Check** / **Bet** / **All-in**
- 前に出ている額があるとき：**Fold** / **Call** / **Raise** / **All-in**
- スタックがコールする額に足りないときは、Call を「Call (All-in)」と表示する。
- 最小レイズに足りない額でも打てる。そのときは額の色を変えて注意を出すだけにする。
- 額は「Raise to（このストリートで出す合計の額）」で表示する。

### 3-3. ベット額の入力（キーボードは出さない）
次の 3 つを、1 枚のパネルに並べる。
1. **ポットの % ボタン**（33% / 50% / 75% / 100% / 150%）
   - **今、場に出ているチップの合計**（前のストリートまでのポットと、このストリートで出された分すべて）を基準にする。
   - **このアクションで新しく出す額 ＝ 今のポット × %**。つまり 100% を打つと、ポットはちょうど 2 倍になる。
   - 新しく出す額がコールする額より少ないボタンは、押せなくする。
2. **± ボタン**：1BB ずつ増減する。長押しすると速く変わる。下限は「コールする額＋最小チップ単位 1 つ分」、上限はスタック全部。
3. **テンキー**：画面の中に描くボタン（0–9 / 00 / 000 / ←）。ちょうどの額を打ちたいときに、タップして開く。

### 3-4. 最小チップ単位（丸め）
- 最小チップ単位（例: 25, 100）を決め、% で出した額をその単位に丸める（いちばん近い値にし、スタックを超えたらスタック全部にする）。
- 初期値は今のレベルの SB にする。設定で値を変えられ、丸めそのものもすぐ切り替えられる（オン／オフ）。
- チョップの端数も同じ単位で分け、余りはボタンの左から数えて最初の勝者に渡す。

---

## 4. 勝敗の入力

ポットごとに勝者を選ぶ。
1. ポットとサイドポットは、各プレイヤーが出した額から自動で計算する。フォールドした人のチップもポットに入るが、その人に受け取る権利はない。
2. まず、メインポット（参加者全員に権利がある）の勝者をタップする。1 人なら Win、複数ならその人たちで Chop。残りの人は自動で Lose。
3. 勝者がすべてのサイドポットにも権利を持っていれば、そこで決まる。
4. 勝者に権利がないサイドポットが残っていれば、その権利を持つ人だけを表示して、次の勝者を選ぶ。これをすべてのポットが決まるまで繰り返す。
5. 確定したら、チップを配って次のハンドへ進む。

---

## 5. UNDO / REDO

- 次の操作を、それぞれ 1 手として戻せる：アクション、勝敗の確定、ハンドの開始、プレイヤーの追加・退席・離席・席の移動、名前の変更、スタックの変更、設定の変更。
- ハンドをまたいでも戻せる。
- 時計（経過時間・一時停止・レベルの手動変更）は UNDO の対象外。手動で変えたレベルは、メニューの「レベルを上げる／下げる」で戻す。
- 新しい操作をしたら、REDO の履歴は消える。
- 履歴も端末に保存し、ページを開き直したあとも戻せるようにする。上限は 500 手で、古いものから消す。
- 実装では、ゲームの状態をまるごと変えられないオブジェクトにし、操作のたびに新しい状態を作って履歴に積む。
- 確認ダイアログは原則出さない（UNDO で戻せるため）。ただし「新しいゲーム」と「プリセットの削除」だけは確認する。

---

## 6. 精算表

- プレイヤーごとに、バイインとリバイの合計、今（または退席したとき）のスタック、その差を表に出す。
- 退席した人も表に残す。
- 「金銭の賭けを推奨するものではありません」という注記を、表と同じ場所に出す。

## 7. 画面（1 ページ）

```
┌──────────────────────────────┐
│ Lv3  200/400/800       12:34 ⏸ │ ← 固定（0 分）なら時計と ⏸ を出さない
│ ↶ ↷                    精算  ⚙ │ ← UNDO/REDO・精算表・設定
├──────────────────────────────┤
│  席の一覧（縦のリスト）              │
│  名前 / スタック / このストリートの額 / D・SB・BB │
│  次に行動する人を強調。タップでメニュー   │
│  （名前・スタックの変更、離席、退席）     │
├──────────────────────────────┤
│ Pot 3,200（Side 1,000）   Flop   │
├──────────────────────────────┤
│ [Fold] [Call] [Raise] [All-in]   │
│ 33% 50% 75% 100% 150%  − 1,200 ＋ │ ← テンキーはタップで開く
└──────────────────────────────┘
```
- 勝敗を入力するときは、下の部分が「勝者を選ぶパネル」に切り替わる。
- 設定（ブラインドテーブル、プリセット、最小チップ単位、丸めのオン／オフ）は、ボトムシートで開く。

---

## 8. その他
- ゲーム中は、画面が消えないようにする（Wake Lock API）。
- 状態は操作のたびに端末に保存する。タブを閉じても、そのまま再開できる。
- 「新しいゲーム」で、今の状態をリセットする（確認あり）。プリセットは残す。
- プリセットと進行中のゲームを、JSON ファイルに書き出したり読み込んだりできる（バックアップ）。

## 9. 初版では扱わないもの
- アンティ、ストラドル（ストラドルが必要なら、トリプルブラインドで代わりにする）
- ハンドの履歴、勝ち数などの統計（あとで足せる設計にはしておく）
- 最小レイズに足りないオールインのあとで、レイズできるかどうかの厳密な判定
